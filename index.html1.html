Cartons comptés

    Lecture du poids sur le code-barres

    Automatique pour les étiquettes GS1 (poids net 310x / brut 330x). Si vos étiquettes sont différentes, apprenez à l'app où se trouve le poids.

    Contrôles
    Alerte code déjà scanné
    Prévient si le même code est scanné deux fois.
    Signaler les poids inhabituels
    Surligne un poids très différent des autres.
    Son à chaque carton
    Petit bip quand un carton est ajouté.
    Comment ça marche
    1. Touchez Scanner un carton. La caméra reste ouverte : placez le code-barres de chaque carton dans le cadre, un bip confirme chaque carton.
    2. L'app lit le poids dans le code et ajoute le carton. Le total se met à jour tout seul. Touchez Terminer le scan à la fin.
    3. Une erreur ? Corrigez ou supprimez seulement la ligne concernée, sans tout recompter.
    4. À la fin, touchez Terminer pour enregistrer le comptage dans l'historique.

    Approchez : le code-barres doit remplir le cadre
